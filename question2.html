Box 1

width: 100% • height: 220px

Fixed pixel height (220px) with full percentage width. Resizes fluidly with parent.

Box 2

min-height: 25vh • max-width: 30em

min-height prevents the box from shrinking below 25% of the viewport height. max-width caps the width at 30em.

Box 3

width: 350px • height: 220px • overflow: auto

This box has a fixed size. When content overflows, the browser shows a scrollbar automatically.
