Responsive Design Principles

The three pillars of responsive web design

Fluid Layouts

Fluid layouts use percentage-based widths instead of fixed pixel values, allowing content to expand and contract relative to the viewport size. 

.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

Flexible Media

Images and media scale within their containers using max-width: 100%, preventing overflow and maintaining aspect ratios across all screen sizes. 

img {
  max-width: 100%;
  height: auto;
  display: block;
}

Breakpoints

CSS media queries define breakpoints where the layout restructures to fit the device. Common breakpoints target mobile, tablet, and desktop widths. 

@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}
