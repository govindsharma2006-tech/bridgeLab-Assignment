CSS Cheat Sheet

Quick reference for key responsive CSS concepts

CSS Filters

CSS filters apply visual effects like blur, grayscale, sepia, brightness, contrast, and hue-rotate to elements. Syntax:

filter: grayscale(100%) blur(2px);

Media Queries

Media queries allow applying styles based on viewport width, height, orientation, and other features. They are the backbone of responsive design.

@media (max-width: 768px) { ... }

Responsive Design

Responsive design ensures layouts adapt to any screen size using fluid grids, flexible images, and CSS breakpoints for an optimal user experience.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Responsive Typography

Use relative units (rem, em, vw) and the clamp() function to create fluid font sizes that scale with the viewport automatically.

font-size: clamp(1rem, 2vw, 1.5rem);
