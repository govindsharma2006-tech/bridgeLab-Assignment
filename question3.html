Linear Gradient

Linear Gradient + Parallax

This section uses linear-gradient(135deg, ...) as the background. The gradient transitions color linearly along a 135-degree diagonal direction.

The background-attachment: fixed; property creates a parallax effect — the background stays fixed to the viewport while content scrolls over it.

Radial Gradient

Radial Gradient Background

This section uses radial-gradient(circle at center, ...). The gradient radiates outward from a central point in a circular pattern.

The bright teal color at the center fades into deep dark blue toward the outer edges of the section.
